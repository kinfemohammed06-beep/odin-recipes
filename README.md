# Traditional Ethiopian Recipes Website

A simple multi-page website highlighting three classic Ethiopian dishes: **Doro Wat**, **Shiro Wat**, and **Kitfo**. Built with clean, standalone HTML5 pages.

---

## 🍽️ Webpages & Content

* **`index.html` — Homepage**
  The main entrance to the website. Provides an overview of traditional Ethiopian dining culture and navigation links to each recipe.
* **`doro-wat.html` — Doro Wat (Spicy Chicken Stew)**
  Ethiopia's famous national dish—tender chicken and hard-boiled eggs simmered in a rich, slow-cooked *berbere* onion sauce.
* **`shiro-wat.html` — Shiro Wat (Chickpea Stew)**
  A popular staple made from seasoned chickpea flour (*shiro*), garlic, and spiced clarified butter (*niter kibbeh*) or oil.
* **`kitfo.html` — Kitfo (Minced Beef Tartare)**
  Finely minced beef infused with warm *niter kibbeh* and spicy *mitmita*, traditionally served alongside *ayib* (cottage cheese) and *gomen* (collard greens).
